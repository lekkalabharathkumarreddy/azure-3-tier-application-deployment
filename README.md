# Azure 3-Tier Application Deployment

## 📌 Project Overview

This project demonstrates the deployment of a 3-tier web application architecture on Microsoft Azure using separate virtual machines for the web, application, and database layers.

## 🏗️ Architecture

User → Nginx → Apache Tomcat → MySQL

## 🛠️ Technologies & Tools

- Microsoft Azure
- Azure Virtual Machines
- MobaXterm
- Linux/Ubuntu
- Nginx
- Apache Tomcat
- MySQL
- Azure NSG
- Git & GitHub
